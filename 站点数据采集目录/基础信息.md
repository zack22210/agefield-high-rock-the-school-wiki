## 2、网站主题色与默认明暗模式

### 结论

建议默认使用**亮色主题**。游戏画面以明亮的春日校园、蓝天、暖黄色校舍和早期 2000 年代的彩色流行朋克视觉为主，亮色更贴合题材，也让攻略正文具有更好的长篇阅读体验。核心品牌色使用 varsity navy（学院海军蓝），辅以 yearbook gold（年鉴金黄）；暗色主题保留同一蓝金关系，但提高亮度保证对比度。

```css
/* 导航页主题色 - 亮色主题（默认） */
--nav-theme: 215 55% 30%;        /* varsity navy #223F77 */
--nav-theme-light: 43 91% 58%;  /* yearbook gold #F6C432 */

/* 导航页主题色 - 暗色主题 */
--nav-theme: 215 65% 60%;        /* brighter varsity blue #5B8BD8 */
--nav-theme-light: 43 92% 65%;  /* brighter yearbook gold #F8D154 */
```

建议配套色：页面背景 `#FFF8E8`、正文 `#172033`、行动按钮/危险强调 `#C73A45`。蓝色传达校徽与校服感，金黄对应阳光与年鉴，红色只用于叛逆、摇滚和 CTA 强调。

### 排序依据

- 游戏 Steam 商店明确支持上述四种语言的界面与字幕，英语另有完整配音；避免网站提供游戏本体并不支持的语言。
